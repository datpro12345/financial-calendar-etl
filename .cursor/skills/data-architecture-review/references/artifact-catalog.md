# Sourced catalog (templates, notation, generators)

Terms: [terminology.md](terminology.md). Rows below are **templates**, **notation**, or **generators** — not this project's architecture. Instantiating one with repository evidence produces an **artifact**. Some artifacts present a **view** of the **architecture model**.

The files in `../templates/` are intentionally small adaptations, not a vendored documentation framework. Attribution lines inside adapted arc42 files are retained because the source is CC BY-SA 4.0; adapted copies must remain CC BY-SA 4.0 with credit, license link, and change notice. “Reference only” means use the format/tool, not copied source material.

## Explicit gaps

- No sourced generic template has been embedded for a data-product **deliverable** package. Use `templates/deliverables/GAP.md` to record audience, acceptance evidence, and the source/template that must be selected later. That gap file is not itself a deliverable.
- No separate sourced functional-requirements template is embedded. ARC-01 handles goals/constraints and ARC-10 handles quality scenarios; use project-native backlog, contract, or specification formats where they already exist.
- Structurizr is supported as an optional external **model** generator, but no template was copied because a current public source template/license was not verified during this packaging pass.
